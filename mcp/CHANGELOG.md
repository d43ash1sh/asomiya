# Changelog — asomiya-mcp

## [0.1.0] — 2026-11-26

First release, with Asomiya 0.5.0.

- Tools: `run_asomiya`, `check_asomiya`, `asomiya_to_python`, `lookup_keyword`, `explain_error`.
- Resources: a tested guide for AI assistants, the language docs, and the example programs.
- Prompts: `teach_asomiya` and `translate_to_asomiya`.
- An in-chat playground (MCP App) for `run_asomiya`: highlighted, editable code, its output, a
  Python view, and a link to asomiya.codes, in light and dark themes.
- `asomiya-mcp --guide` prints the guide for AI assistants.
- A Claude Desktop extension (`.mcpb`), and a listing in the MCP Registry as
  `io.github.d43ash1sh/asomiya`.
